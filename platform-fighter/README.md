# Platform Fighter 🎮

A multiplayer platform fighting game with 1v1 and Free-For-All modes.

## Features
- **1v1 Mode**: Two players battle on a platform. First to fall loses!
- **Free-For-All Mode**: Up to 8 players battle with respawns
- Real-time multiplayer using WebSockets
- Simple but satisfying physics with knockback
- Clean, responsive UI

## How to Play
1. Open the game in your browser
2. Choose a game mode
3. Wait for opponents to join
4. Fight using:
   - **A/D or ←/→**: Move left/right
   - **W or ↑ or Space**: Jump
   - **J or K**: Attack
